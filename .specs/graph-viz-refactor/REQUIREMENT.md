## 用户故事

### 增量修改（覆盖 frontend-ui 中的对应条目）

- **US-5（改写）**：作为管理员，我想**在 WebGL 渲染的画布上查看文档的知识图谱子图**，以便流畅地浏览和探索节点间的关联关系，不再遇到白屏或卡顿。
- **US-5a（新增）**：作为管理员，我想**查看融合后的全量知识图谱**，以便从全局视角理解跨文档、跨学科的知识点网络结构。
- **US-5b（新增）**：作为管理员，我想**在图谱中搜索节点、按类型筛选、点击查看详情、展开邻域节点**，以便高效定位和探索特定知识点及其关联。
- **US-5c（新增）**：作为管理员，我想**查看智能问答剪枝出的子图**（含节点属性和边权重），以便理解 LLM 诊断结论的图数据依据。

## 验收准则（AC）

### AC-10（改写自 frontend-ui AC-10）· 文档子图 G6 渲染

- **Given** 某文档已完成知识图谱抽取（状态为 EXTRACTED 或 COMPLETED）
- **When** 用户在图谱可视化页选择该文档
- **Then** 画布使用 AntV G6 v5 渲染节点-边图：节点按 `nodeType` 显示不同颜色和大小，边按 `edgeType` 显示不同颜色和线型（实线/虚线），边标签显示类型名；支持滚轮缩放和拖拽平移；画布**不出现白屏**
- **验证方式**: 选择已抽取文档，确认画布在 3 秒内渲染出连通图，滚轮缩放/拖拽平移流畅

### AC-11（从 frontend-ui v2 提至 v1）· 剪枝子图可视化

- **Given** 用户已通过智能问答获得一份诊断报告（存在 `taskId` 对应的 `SubgraphResponse`）
- **When** 用户在图谱可视化页加载该 `taskId` 的剪枝子图
- **Then** 画布渲染节点-边图：节点悬浮显示 `properties` 中的 `name`/`label` 等字段，边按 `weight` 显示不同粗细，侧面板显示剪枝元信息（策略名、阈值、节点/边总数、是否截断）
- **验证方式**: 问答完成后加载对应 taskId 的子图，悬停节点确认属性浮窗出现，确认元信息面板数据完整

### AC-15（新增）· 节点搜索与定位

- **Given** 画布中已渲染图谱（≥ 10 个节点）
- **When** 用户在搜索框中输入节点 ID 或名称关键词（至少 2 个字符）
- **Then** 匹配的节点列表在下拉框中实时显示（防抖 300ms）；用户选中某一结果后，画布自动平移到该节点居中，节点高亮（边框加粗 + 发光），其余节点降低透明度
- **验证方式**: 输入已知节点 ID 前缀，确认下拉列表出现匹配结果，点击后确认画布居中并高亮

### AC-16（新增）· 类型筛选与图例

- **Given** 画布中已渲染包含多种节点类型和边类型的图谱
- **When** 用户在图例面板中取消勾选某一节点类型（如 Entity）或边类型（如 REFERENCES）
- **Then** 对应类型的节点/边立即隐藏；重新勾选后恢复显示；图例面板列出当前图中所有存在的类型及其颜色标注
- **验证方式**: 取消勾选 KnowledgePoint 类型，确认蓝色节点消失；重新勾选后恢复

### AC-17（新增）· 节点详情与邻域展开

- **Given** 画布中已渲染图谱
- **When** 用户单击某一节点
- **Then** 侧边弹出详情面板，显示节点 ID、类型、properties 中所有字段；面板中提供「展开邻域」按钮 — 点击后以该节点为中心，高亮其 1 跳邻居节点和连接边，其余节点/边降低透明度
- **验证方式**: 点击一个 KnowledgePoint 节点，确认详情面板显示属性，点击展开邻域确认仅邻居高亮

### AC-18（新增）· 全量融合图谱加载

- **Given** 系统已执行过至少一次全量融合（存在融合后的完整图谱数据）
- **When** 用户在图谱可视化页切换到「全量图谱」视图
- **Then** 画布加载全量图谱数据并渲染；加载期间显示 skeleton 占位；若节点数 > 1000，渲染完成后帧率 ≥ 30fps（通过拖拽/缩放感知，无明显卡顿）
- **验证方式**: 切换到全量图谱，确认加载完成，拖拽/缩放流畅

### AC-19（新增）· 路径高亮

- **Given** 画布中已渲染图谱
- **When** 用户在搜索框中先选中节点 A，再按住 Ctrl/Cmd 点击节点 B
- **Then** 画布高亮 A→B 的最短路径（节点和边），其余节点/边降低透明度；路径上的边加粗显示
- **验证方式**: 选中两个有路径连通的节点，确认路径高亮

## 范围切分

### v1（本次必做）

- AntV G6 v5 替换 Cytoscape.js，WebGL 渲染
- 文档子图渲染（`GraphSubgraphVO` 适配）
- 剪枝子图渲染（`SubgraphResponse` 适配，含 properties 浮窗 + 元信息面板）
- 全量融合图谱视图
- 节点搜索与定位
- 类型筛选与图例面板
- 节点单击 → 详情侧面板 + 邻域展开
- 路径高亮（双节点最短路径）
- 加载态 skeleton、空态提示、错误态提示

### v2（下一轮考虑，不本次）

- 布局算法切换（力导向 / 同心圆 / 网格 / 径向）
- 鱼眼放大镜（fisheye lens）
- 小地图（minimap）缩略导航
- 图谱导出（PNG / SVG / JSON）
- 节点聚合（大图场景下按类型/社区折叠）
- 边权重阈值滑块过滤
- 历史面包屑（节点跳转回退/前进）
- 键盘快捷键完整支持（Delete 取消选中、方向键微调等）

### out（永远不做）

- 图谱编辑（节点/边的增删改 — 后端无写入 API）
- 图谱深色模式（跟随全局 V1 决策）
- 移动端触摸手势适配
- 实时协作/多人标注

## 非功能性需求

- **性能**: 全量图谱 ≤ 5000 节点时帧率 ≥ 30fps（拖拽/缩放期间）；首个子图渲染 ≤ 3s；搜索防抖 300ms
- **可访问性**: 搜索框支持键盘 Escape 关闭下拉；类型筛选图例支持 Tab 键导航；节点颜色 + 形状双重编码（色觉障碍友好，继承 `NODE_COLORS` 映射）
- **安全**: 无新增安全面（纯前端渲染，数据来自后端已有 API）
- **兼容性**: Chrome 120+、Firefox 120+、Edge 120+（桌面端，≥1280px）；需 WebGL 1.0 支持（G6 v5 硬依赖）
- **可观测性**: G6 实例创建/销毁在 console.debug 输出（开发模式）；渲染异常通过页面级 ErrorBoundary 捕获并显示友好提示

## 依赖与假设

- **后端 API 不变**：`GET /api/v1/graph/construction/document/{documentId}` 和 `GET /api/v1/analysis/subgraph/{taskId}` 端点响应结构不变
- **全量图谱 API**：假设存在或本次会新增全量图谱查询端点（待 DESIGN 阶段确认 — 若不存在需后端配合新增，或在 v1 中通过前端聚合现有端点数据模拟）
- **G6 v5 稳定版本**：锁定 `@antv/g6` ^5.0.0 大版本，避免 minor 更新引入 API breaking change
- **WebGL 可用性**：假设目标浏览器均支持 WebGL 1.0（Chrome/Firefox/Edge 120+ 均满足）
- **既有设计 token 不变**：继承 `frontend-ui` 的 CSS variables 和调性，图谱画布颜色映射沿用现有 `NODE_COLORS` / `EDGE_COLORS` 常量
- **测试数据**：开发环境 podman 中 Neo4j 已有图谱数据可供联调
