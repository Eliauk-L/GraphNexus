## 二、组件清单

### 2.1 公网

| 组件 | 构造型 | 说明 |
|------|--------|------|
| **PC 浏览器** | `«client»` | 用户通过浏览器访问系统 |

### 2.2 内网 — 接入层

| 组件 | 构造型 | 端口 | 说明 |
|------|--------|------|------|
| **Nginx** | `«device»` | :80 | 反向代理 + 负载均衡，公网进入内网的唯一入口 |

### 2.3 内网 — 业务服务区

两个 GraphNexus 实例封装在同一逻辑分组内：

| 组件 | 构造型 | 端口 | 说明 |
|------|--------|------|------|
| **GraphNexus 实例 1** | `«server»` | :8081 | 业务服务副本 1 |
| **GraphNexus 实例 2** | `«server»` | :8082 | 业务服务副本 2 |

### 2.4 内网 — 数据服务区

| 组件 | 构造型 | 端口 | 说明 |
|------|--------|------|------|
| **Neo4j** | `«database»` | :7687 | 图数据库，存储宽图谱节点和关系 |
| **MySQL** | `«database»` | :3306 | 关系数据库，存储元数据和配置 |
| **MinIO** | `«storage»` | :9000 | 对象存储，PDF/CSV/备份文件 |
| **RabbitMQ** | `«queue»` | :5672 | 消息队列，异步任务编排 |
| **Redis** | `«cache»` | :6379 | 缓存中间件，会话共享和查询缓存 |

### 2.5 外部服务

| 组件 | 说明 |
|------|------|
| **外部 LLM API** | 位于系统边界之外，业务服务区通过 HTTPS 虚线连接调用 |

## 三、连接关系与协议

> 每条连接在 drawio 中均**显式标注了协议标签**。

### 3.1 协议标注总览

| # | 源 | 目标 | 端口 | 协议 | 线型 | 方向 |
|---|------|------|------|------|------|------|
| ① | PC浏览器 | Nginx | 80 | **HTTP** | 实线 | 正向 |
| ② | Nginx | GraphNexus实例 | 8081/8082 | **HTTP** | 实线 | 正向 |
| ③ | GraphNexus实例 | Neo4j | 7687 | **BOLT** | 实线 | 正向 |
| ④ | GraphNexus实例 | MySQL | 3306 | **JDBC** | 实线 | 正向 |
| ⑤ | GraphNexus实例 | MinIO | 9000 | **HTTP** | 实线 | 正向 |
| ⑥ | GraphNexus实例 | RabbitMQ | 5672 | **AMQP** | 实线 | 正向 |
| ⑦ | GraphNexus实例 | Redis | 6379 | **HTTP** | 实线 | 正向 |
| ⑧ | GraphNexus实例 | 外部LLM API | 443 | **HTTPS** | 虚线 | 正向 |
| ⑨ | RabbitMQ | GraphNexus实例 | 5672 | **AMQP** | 实线 | 反向 |
| ⑩ | Redis | PC浏览器 | — | **HTTP** | 实线 | 反向 |

### 3.2 正向请求链路

```
PC 浏览器 ── HTTP ──▶ Nginx :80
                          │
                          │ HTTP
                          ▼
               ┌─────────────────────┐
               │   GraphNexus 业务服务  │
               │  实例1 :8081         │
               │  实例2 :8082         │
               └──────────┬──────────┘
                          │
    ┌──────┬──────┬───────┼───────┬──────┬──────────┐
    │ BOLT │ JDBC │ HTTP  │       │ AMQP │ HTTP     │
    ▼      ▼      ▼      ▼       ▼      ▼          ▼
  Neo4j  MySQL  MinIO  Redis  RabbitMQ  外部LLM API
  :7687  :3306  :9000  :6379   :5672   (HTTPS)
```

### 3.3 反向链路（异步回调 / 缓存回源）

```
RabbitMQ :5672 ── AMQP ──▶ GraphNexus 业务服务    （消费者回调）
Redis :6379    ── HTTP ──▶ PC 浏览器              （缓存回源数据流）
```

## 四、网络区域说明

| 区域 | 包含组件 | 访问策略 |
|------|---------|---------|
| **公网** | PC 浏览器 | 用户终端，任意公网 IP |
| **内网** | Nginx, GraphNexus 实例, Neo4j, MySQL, MinIO, RabbitMQ, Redis | 仅 Nginx 暴露给公网，其余组件仅内网可达 |
| **外部** | LLM API | 业务服务从内网发起 HTTPS 出站调用，虚线表示跨边界连接 |
