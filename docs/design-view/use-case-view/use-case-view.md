### 1.2 参与者详表

| # | 参与者 | 核心职责 | 用例数 |
|---|--------|---------|--------|
| **A1** | 管理员 (Administrator) | 管理数据资产与系统权限 | 20 |
| **A2** | 教师 (Teacher) | 消费分析结果与生产教学数据 | 16 |
| **A3** | 学生 (Student) | 感知自身学习状态 | 6 |
| **A4** | 运维人员 (Operations Staff) | 保障系统稳定运行 | 14 |
| **A5** | 运营人员 (Operations Manager) | 度量系统使用效果 | 6 |

### 1.3 参与者关系

```
  管理员(A1) ──泛化──▶ 教师(A2)      （管理员继承教师全部用例）

  学生(A3) 、 运维人员(A4) 、 运营人员(A5) 为独立参与者
```

### UC-21 · 查询薄弱点归因 (P0)

| 维度 | 说明 |
|------|------|
| **用例编号** | UC-21 |
| **参与者** | 教师 (A2) |
| **来源 Story** | 2.1 |
| **优先级** | P0 — 系统核心价值主张 |
| **前置条件** | 宽图谱已融合；UC-08 剪枝策略和 UC-10 权重规则已配置；LLM 服务可用 |
| **后置条件（成功）** | 返回结构化归因报告（根因列表 + 多维证据链 + 置信度 + 原文引用） |
| **后置条件（失败）** | 返回错误提示（权限不足 / 数据不足 / LLM 不可用 / 配额耗尽） |

**主成功流程**：

```
1.  教师以自然语言或结构化方式输入查询
2.  [«include» UC-20] 系统校验教师角色及任教班级数据范围
3.  系统识别查询意图并路由到"归因分析"任务类型
4.  [«include» UC-08] 剪枝引擎按配置的策略从宽图谱提取子图
5.  上下文构建器将子图序列化为 LLM 可理解的结构
6.  LLM 网关调用 AI 服务生成分析结果
7.  系统返回结构化归因报告：
    · 薄弱根因列表（按影响程度降序）
    · 每项根因的多维证据链
    · 置信度标注（高/中/低）
    · 关键数据附带原文引用
```

**异常处理**：教师无权访问 → 403；子图为空 → 提示数据不足；LLM 不可用 → 降级切换备用模型；配额耗尽 → 提示联系管理员。

### 6.2 分层调用路径

```

                                    ↑ 横切面: 日志/备份/监控/定时任务/通知 (纵向贯穿 L0~L3)
```

| 入口界面 | 用例范围 | L0 用户 | L1 网关 | L2 应用层业务区域 | L3 基础设施 |

> **说明**：P1/P4 为管理/运维类入口，用户直接操作 L2 业务区域；P2/P3/P5 为应用类入口，通过 L2 智能查询区域编排调用其他业务区域。
