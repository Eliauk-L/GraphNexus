# 教师视角：基于图谱技术的 AI 精准问答系统 — 问题类型与提问策略

> 本文档模拟一名资深教师使用"基于图谱技术的 AI 上下文处理与精准问答系统"时，会提出的各类问题及其提问思路。重点演示"学生知识点薄弱归因分析"的多轮递进式提问方法。

---

## 二、重点演示：知识点薄弱归因分析的多轮提问思路

以"学生A二次函数薄弱"为例，展示一位教师如何由浅入深、层层递进地提问。

---

### 第一轮：事实确认 —— "弱在哪里？"

> **老师提问：**
>
> "学生A在'二次函数'这个知识点上的整体掌握情况如何？请列出他的历次相关考试/作业成绩、错误类型分布，以及这个知识点的上下游关联图谱。"

**期望系统产出：**

系统从宽图谱中剪枝出「学生A → 二次函数」相关的子图，包含：
- 历次考试记录（事件节点）
- 错误题目对应的具体子知识点（如顶点式、判别式、图像平移）
- 前置知识点（一次函数、完全平方公式、坐标系）和下游知识点（二次不等式、导数入门）

---

### 第二轮：纵向追溯 —— "什么时候开始弱的？"

> **老师提问：**
>
> "往前追溯学生A的学习轨迹，他是在哪个时间点开始出现'二次函数'相关题目正确率下降的？当时他正在学什么前置知识点？那个前置知识点的掌握情况如何？"

**期望系统产出：**

沿着时间轴和知识图谱的依赖边，定位到"完全平方公式"这个前置知识点在学生A的图谱中掌握权重较低（比如 0.3/1.0），且在学完该知识点后的第一次"二次函数配方法"作业中正确率骤降。

---

### 第三轮：横向对比 —— "别人也这样吗？"

> **老师提问：**
>
> "同样在'二次函数'上表现薄弱的学生，他们的知识图谱中，前置薄弱点是否也集中在'完全平方公式'？还是各有不同的薄弱路径？请做一个对比分析。"

**期望系统产出：**

系统对多个薄弱学生的图谱做路径聚类——发现 65% 的学生薄弱路径为"完全平方公式 → 配方法 → 二次函数"，20% 为"坐标系理解 → 图像平移 → 二次函数"，15% 为其他路径。学生A属于多数派。

---

### 第四轮：行为关联 —— "和课堂表现有关吗？"

> **老师提问：**
>
> "结合学生A的课堂行为记录（出勤、作业提交准时性、课堂互动频率），分析这些非学业因素与他的'二次函数'薄弱之间是否存在关联？例如，他在讲'配方法'那几节课的课堂互动是否明显偏低？"

**期望系统产出：**

系统发现学生A在"配方法"相关课堂记录中互动次数为 0（同期全班平均 3.2 次），且对应的那次课后作业迟交了 3 天。图谱中的行为节点与知识点节点的关联权重异常。

---

### 第五轮：干预建议 —— "怎么办？"

> **老师提问：**
>
> "综合以上分析，请给出针对学生A的具体干预方案：需要补哪些前置知识、按什么顺序补、推荐哪些教辅资料中的对应章节、预计需要多少练习量，以及干预后应重点观察哪些下游知识点的变化。"

**期望系统产出：**

系统基于子图生成具体方案：
1. **先补**"完全平方公式"（教辅 PDF 第 2.3 节，3 道基础练习）
2. **再补**"配方法"（教辅 PDF 第 3.1 节，配合 2 道图像联动题）
3. **最后**回到"二次函数"综合题
4. 预计干预周期 2 周，重点观察下游"二次不等式"的掌握权重是否回升

---

### 第六轮：闭环验证 —— "效果如何？"

> **老师提问（2 周后）：**
>
> "系统已录入学生A这两周的补习练习和最新一次测验成绩。请对比干预前后的图谱变化，评估本次归因分析和干预方案是否有效。如果效果不达预期，重新分析可能遗漏的因素。"

**期望系统产出：**

图谱更新后，学生A的"完全平方公式"掌握权重从 0.3 → 0.7，"二次函数"从 0.25 → 0.55。系统自动标记"二次不等式"作为下一观察节点。若效果不达预期，系统触发"遗漏因素探测"——如是否忽略了"考试焦虑"等非认知因素。

---

## 三、总结：教师提问的模式特征

通过以上梳理，可以发现使用该系统时的提问遵循一套核心模式：

```
事实描述（是什么）
  → 纵向追溯（从什么时候开始）
    → 横向对比（别人也这样吗）
      → 多维关联（和行为/态度/教学有关吗）
        → 干预建议（怎么办）
          → 闭环验证（效果如何）
```

这正是文档中 **"任务驱动剪枝 → 子图输入 LLM → 归因分析 → 动态更新"** 这条技术链路在教学场景中的自然映射。每次提问都是一次"任务"，系统根据任务类型剪枝出不同范围的子图，为 LLM 提供精准上下文，而不是把整个宽图谱一股脑喂进去。

### 核心洞察

| 维度 | 说明 |
|------|------|
| **图谱的厚度决定答案的深度** | 只有融合了成绩、行为、教辅资料的"宽图谱"，才能支撑从"是什么"到"为什么"再到"怎么办"的完整推理链 |
| **剪枝策略决定答案的精度** | 不同问题需要不同范围的子图——归因分析需要沿时间轴 + 依赖边双向展开，而班级概览只需要横向聚合 |
| **动态更新决定系统的生命力** | 干预后的图谱变化既是上一次分析的闭环验证，也是下一次分析的起点，形成"诊断 → 干预 → 验证 → 再诊断"的教学飞轮 |
